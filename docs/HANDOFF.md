Тимофей, ВАЖНО — выполни это один раз после `git pull`:

    git config core.hooksPath .githooks

Включает хук, который не даст случайно запушить в `main`. Без этой команды
хук не работает — git не подхватывает её из репозитория сам. Защиту веток
на самом GitHub включить не вышло: она платная для приватных репозиториев,
так что хук — единственное, что нас страхует.
