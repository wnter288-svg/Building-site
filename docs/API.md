# API — контракт фронт/бэк

Эндпоинт живёт внутри Astro-проекта (`frontend/src/pages/api/`) и
выполняется на сервере Vercel. Отдельного Express-сервиса нет.

---

## POST /api/lead

Приём заявки с формы и отправка её в Telegram.

**Запрос:**

```json
{
  "name": "Данило",
  "tel": "+380441234567",
  "loc": "Обухівський напрямок",
  "area": "240",
  "msg": "Є ділянка, потрібен проєкт",
  "consent": true,
  "website": ""
}
```

| Поле | Обяз. | Ограничения |
|---|---|---|
| `name` | да | 2–80 символов |
| `tel` | да | украинский номер: `+380XXXXXXXXX` или `0XXXXXXXXX` |
| `loc` | нет | до 120 символов |
| `area` | нет | до 20 символов |
| `msg` | нет | до 1000 символов |
| `consent` | да | должно быть `true` |
| `website` | — | honeypot: люди его не видят и не заполняют |

Всё, что длиннее лимита, обрезается, а не отклоняется.

**Ответы:**

| Код | Тело | Когда |
|---|---|---|
| `200` | `{"ok":true}` | заявка ушла в Telegram |
| `200` | `{"ok":true}` | сработал honeypot — боту отвечаем успехом, но никуда не шлём |
| `422` | `{"error":"validation","fields":{...}}` | поля не прошли проверку; в `fields` тексты ошибок на украинском |
| `429` | `{"error":"rate"}` | больше 5 заявок с одного IP за 10 минут; заголовок `Retry-After` в секундах |
| `400` | `{"error":"bad_request"}` | тело не разобралось как JSON |
| `503` | `{"error":"not_configured"}` | на сервере не заданы переменные Telegram |
| `502` | `{"error":"delivery"}` | Telegram не принял сообщение |
| `405` | `{"error":"method_not_allowed"}` | любой метод кроме POST |

Тело ответа Telegram наружу не отдаётся никогда — в нём может оказаться
фрагмент токена. Оно пишется только в серверный лог.

---

## Схема проверки

`frontend/src/lib/validation.ts` — **одна и та же** на клиенте и на
сервере. Клиентская нужна, чтобы человек увидел ошибку сразу; серверная
обязательна, потому что клиентскую обходят за минуту любым HTTP-клиентом.

Телефон нормализуется к виду `+380XXXXXXXXX`: принимаются записи с
пробелами, скобками, дефисами и с ведущим `0`.

## Переменные окружения

| Имя | Где задаётся |
|---|---|
| `TELEGRAM_BOT_TOKEN` | локально `frontend/.env`, на проде — Vercel |
| `TELEGRAM_CHAT_ID` | там же |

Образец — `frontend/.env.example`. В репозиторий значения не попадают.
