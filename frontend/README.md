# frontend — сайт DIMORA

Лендинг строительной компании. Astro + TypeScript, без UI-библиотек.

## Запуск

```
npm install
npm run dev
```

Откроется на http://localhost:4321

| Команда | Что делает |
|---|---|
| `npm run dev` | локальный сервер с горячей перезагрузкой |
| `npm run build` | продакшен-сборка |
| `npm run preview` | посмотреть собранное |
| `npx astro check` | проверка типов |

## Что где

| Нужно | Файл |
|---|---|
| Поменять любой текст | `src/content/site.ts` |
| Заполнить телефон, почту, сроки | `src/content/site.ts`, блок `todo` |
| Скрыть/показать секцию «Проєкти» | `src/content/site.ts`, `showProjects` |
| Поправить цвет или кегль | `src/styles/tokens/` |
| Обработчик заявки | `src/pages/api/lead.ts` |
| Поведение страницы | `src/scripts/behaviors.ts` |

**Текста в компонентах нет** — только в `content/site.ts`.
**Цветов и размеров в компонентах нет** — только в `styles/tokens/`.

## Форма заявки

Чтобы форма реально отправляла в Telegram, нужен `.env` (см.
`.env.example`). Без него эндпоинт отвечает `503`, а форма показывает
ошибку — притворяться успехом нельзя, иначе клиент будет ждать звонка.

Настройка бота и переменных — в `../docs/DEPLOY.md`.

## Дизайн

Макет и токены — проект в Claude Design. Токены перенесены в
`src/styles/tokens/` без изменений, вёрстка повторяет макет.

Логотип — `src/components/ui/Logo.astro`: буквы в кривых, поэтому шрифт
Cinzel не подключается вовсе и логотип не зависит от загрузки шрифтов.
