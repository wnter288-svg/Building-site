# Building-site

Учебный проект: двое учатся работать в паре через Claude Code — git,
ветки, PR, разделение зон, документация. Предмет тренировки — лендинг
строительной компании DIMORA.

Делают двое: Тимофей (frontend) и Даня (backend + инфраструктура), каждый
в своём Claude Code, синхронизация через этот репозиторий.

---

## С чего начать

| Ты | Читай в таком порядке |
|---|---|
| Впервые в проекте (человек или ИИ) | `docs/PROJECT.md` → `docs/STRUCTURE.md` → `TODO.md` |
| Садишься работать | `docs/HANDOFF.md` → `docs/PROGRESS.md` → `TODO.md` |
| Правила работы в репозитории | `CLAUDE.md` |
| Выкатываешь на сайт | `docs/DEPLOY.md` |
| Формат заявки | `docs/API.md` |

## Запуск

```bash
cd frontend && npm install && npm run dev
```

Подробности — в [frontend/README.md](frontend/README.md).

## Настройка машины (один раз после клонирования)

```bash
git config core.hooksPath .githooks
```

Включает хук, который не даст случайно запушить в `main`. **Обязательно
для обоих разработчиков** — git не подхватывает хуки из репозитория сам.

## Ветки

- `dev` — рабочая, сюда коммитим и пушим
- `main` — стабильная, только через Pull Request; мердж публикует сайт

## Навыки Claude Code

В `.claude/skills/` — общие навыки, подхватываются автоматически:

- `/project-docs` — привести документацию в соответствие с кодом
- `/project-structure` — проверить и почистить структуру
- `/test-project` — прогнать работоспособность и безопасность
- `/advisor` — рекомендации и запасные планы
